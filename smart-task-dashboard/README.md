## Smart Task Management Dashboard


## Problem Statement

Individuals and small teams often struggle to organize daily tasks, track progress, and manage
priorities efficiently. Many existing tools are either too complex or require backend integration. The objective of this project is to build a frontend-only task management dashboard that allows users to create, manage, and track tasks using a clean and interactive UI. All data will be handled on the client side.


## Functions Implemented

- Add tasks with title, description, priority, and due date  
- Edit and delete tasks  
- Track task status (To Do, In Progress, Completed)  
- Visual indicators for task status  
- Filter tasks by status and priority  
- Sort tasks by due date  
- Store tasks using browser localStorage  
- Display dashboard summary (Total, Completed, Pending)


## Tech Stack

- React.js (Functional Components)
- JavaScript (ES6+)
- CSS
- Browser localStorage API
